# BioJam Information System Analysis & Design

## Overview

This repository contains an academic systems analysis and design project for **BioJam**, a fictional company that produces jam from organic fruits.

The project focuses on the analysis and design of a new Information System that aims to improve the company's internal operations, especially in the areas of procurement, inventory management, customer orders, production, deliveries, and business reporting.

The proposed system is designed to help BioJam reduce manual errors, improve stock control, automate order-related processes, support customer credibility checks, and provide better information for decision-making.

## Project Context

BioJam currently faces several operational issues, such as:

* Manual handling of procurement and inventory data
* Inaccurate ordering of raw materials
* Customer orders being recorded mainly by phone
* Missing or bypassed approval procedures
* Limited use of historical business data
* Delays and errors in order execution
* Need for connection with the accountant's software system

The goal of the project is to analyze these problems and propose a structured Information System that supports the company's business needs.

## Main Objectives

The proposed Information System aims to:

* Record and manage procurement data
* Monitor inventory levels in real time
* Suggest order quantities based on stock and historical data
* Support customer credibility checks
* Automate order approval and delivery-related procedures
* Improve communication between employees
* Support reporting and business decision-making
* Connect with the existing accounting software

## Requirements

### Functional Requirements

The system is expected to support functions such as:

* Registration of raw material orders
* Recording of historical data
* Calculation of suggested order quantities
* Management of order limits
* Recording and monitoring of customer orders
* Inventory updates
* Retrieval of data from the accountant's system

### Non-Functional Requirements

The system also considers non-functional aspects such as:

* Reliability
* Data accuracy
* User access control
* Support for customer credibility checks
* Usability for internal company staff
* Maintainability and technical support
